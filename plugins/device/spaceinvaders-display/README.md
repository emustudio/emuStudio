# Space Invaders display

Emulates the 1978 Midway Space Invaders display, input switches, and 16-bit shift register for an Intel 8080 virtual
computer. The plugin reads the 1-bit framebuffer at 2400h-3FFFh and produces alternating RST 1/RST 2 interrupts.

Original Space Invaders ROM images are not distributed with emuStudio.
